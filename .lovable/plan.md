# Infeworks — من "موقع نضيف" إلى موقع شركة إنشاءات عالمية

## المشكلة الحالية
الموقع دلوقتي صفحتين بس، ومعلوماته قليلة، ومفيش حركة ولا إحساس بالحجم. مواقع زي Hassan Allam و Orascom و Bechtel و Ferrovial بتشتغل على 4 حاجات إحنا ناقصينها:

1. **عمق المحتوى** — قطاعات، خدمات، أرقام، شهادات، مسار زمني، صفحة عن الشركة، طريقة تواصل حقيقية. الموقع الحالي مفيهوش غير Hero + 3 مشاريع.
2. **دليل وثقة** — شعارات عملاء، اعتمادات (ISO)، أرقام موثقة (m³/day منفّذة، سنين خبرة، مشاريع مسلّمة)، اقتباس من عميل.
3. **حركة سينمائية مضبوطة** — مش أنيميشن مرح، لكن reveal هادي عند الскرول، أرقام بتعدّ، صور بتتحرك ببطء (parallax خفيف)، خطوط بترسم نفسها زي رسم هندسي.
4. **إحكام التفاصيل** — نظام شبكة واضح، تنقّل يشتغل على الموبايل، حالة hover مدروسة، مؤشر تقدّم القراءة، صور بتتحمّل بسلاسة.

## الخطة

### أ. هيكل الموقع (من صفحتين لسبعة)
- `/` — الصفحة الرئيسية (إعادة بناء أعمق)
- `/about` — الشركة: الفلسفة "One Line"، مسار زمني، القيادة، الاعتمادات
- `/capabilities` — التسليم المتكامل: تصميم / توريد / تنفيذ / تشغيل بتفصيل تقني
- `/sectors` — الدولة · الصناعي · الزراعي، ولكل قطاع تحدياته والحل
- `/projects` — فهرس المشاريع كله بفلترة (قطاع / سعة)
- `/projects/sadat-city-ro` — دراسة الحالة (تتحسّن)
- `/contact` — نموذج استفسار (frontend فقط) + بيانات المقر

### ب. الصفحة الرئيسية الجديدة (تتابع سينمائي)
1. **Hero** — طبقة صورة بحركة بطيئة (scale خفيف)، عنوان ضخم يظهر سطر سطر، مؤشر سكرول.
2. **شريط أرقام** — أرقام بتعدّ لما تدخل الشاشة: 15 مشروع · 12,000+ m³/day منفّذة · 22 محطة · 100% تسليم في الموعد.
3. **بيان "One Line"** — نص كبير + رسم خطي أفقي بيتحرك يمثّل: تصميم → توريد → تنفيذ → تشغيل، وكل مرحلة بتتفعّل مع السكرول.
4. **القطاعات** — ثلاث لوحات كبيرة، الصورة بتتشبّع باللون عند الـ hover.
5. **المشاريع** — أول مشروع كبير عريض + الباقي شبكة، مع كشف الصورة عند الدخول.
6. **الدليل** — اعتمادات، اقتباس عميل، شعارات الجهات (تايبوغرافي مش صور مزيفة).
7. **إغلاق** — دعوة تواصل بحجم كبير.

### ج. صفحة دراسة الحالة
- بلوك بيانات المشروع لاصق (sticky) جانبي على الشاشات الكبيرة: العميل، الاستشاري، السعة، النطاق، السنة.
- مؤشر تقدّم قراءة رقيق أعلى الصفحة.
- The Challenge → Engineering Scope → Execution → Results، مع جدول مواصفات تقنية وصور بعرض الشاشة بينهم.
- شريط تنقّل "المشروع التالي" في النهاية.

### د. نظام الحركة (منضبط، هندسي)
- `IntersectionObserver` واحد يكشف العناصر: ظهور + إزاحة 12px، مدة 600ms، منحنى هادي، بدون ارتداد.
- الأرقام تعدّ مرة واحدة عند الظهور.
- الخطوط الفاصلة "بترسم" نفسها من اليسار لليمين (scaleX).
- parallax خفيف جدًا على صور الأقسام (translateY بحدود 6%).
- احترام `prefers-reduced-motion` — كل الحركة تتوقف.

### هـ. تفاصيل الاحتراف
- **نافيجيشن**: قائمة موبايل بشاشة كاملة، شريط بيتقلّص عند السكرول، رابط الصفحة الحالية واضح.
- **تايبوغرافي**: تدرّج أحكم — عناوين display ضخمة، متن 17px مع تباعد سطور مريح، أرقام tabular.
- **اللون**: نفس الاتجاه (أبيض صارخ / رمادي أسمنتي / كحلي غامق) + لون واحد accent هندسي رقيق للحالات النشطة فقط.
- **صور جديدة**: لقطة قطاعات، بورتريه عمليات، مضخات/لوحات كهربية، صورة ختام.
- **SEO**: عنوان ووصف و OG لكل صفحة، H1 واحد، alt text وصفي، JSON-LD لمنظمة إنشاءات.
- Loading skeleton بسيط للصور + عرض/ارتفاع محدد لمنع الاهتزاز.
